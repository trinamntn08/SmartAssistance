# Architecture decision records

Use ADRs for decisions that materially affect architecture, security, data,
operations, cost, or the ability to change direction later.

Copy `0000-template.md` to the next sequential number, use a short kebab-case
title, and set its status to `Proposed`. Do not rewrite accepted history. When a
decision changes, add a new ADR and mark the old one `Superseded by ADR-NNNN`.
